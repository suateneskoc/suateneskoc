# Technology

The site currently uses:

- [Next.js](https://nextjs.org/) and [React](https://react.dev/) for the site.
- [Tailwind CSS](https://tailwindcss.com/) for styling.
- [Keystatic](https://keystatic.com/) for content editing.
- [Better Auth](https://www.better-auth.com/) with PostgreSQL for authentication.
- [Bun](https://bun.sh/) for package management and scripts.
- [Playwright](https://playwright.dev/) and [axe-core](https://github.com/dequelabs/axe-core) for browser and accessibility testing.

Update this page when the project adopts a significant technology or replaces
an existing one.
